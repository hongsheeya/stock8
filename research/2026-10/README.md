# 2026-10 전략 검증 스크립트 모음

앱의 매매 규칙을 정하거나 바꿀 때 근거로 쓴 백테스트·분석 스크립트입니다.
시세 데이터(캐시, 캔들, 분봉 아카이브)는 용량이 커서 넣지 않았습니다. 다시 돌리려면 각 스크립트의 내려받기 단계(yfinance, 업비트, KIS 분봉 아카이브)를 먼저 실행해야 합니다.

| 폴더 | 내용 | 반영된 결정 |
|---|---|---|
| `ks/` | 국장 방향추세 단타 (1년 KIS 1분봉) | 갭상승 날 09:15 BULL, 시가 대비 2.5% 넘게 움직였으면 진입 안 함, 하루 한 번 진입, 익절 없음 |
| `us/` | 미장 장중 추세·되돌림, 일봉 돌파, 일봉 추세 필터 | 미장 단타 탈락 → 모의 신규 진입 OFF, 일봉 추세 보유(QLD·SSO, 6개월 모멘텀)를 모의로 운용 |
| `coin/` | 업비트 코인 전략 연구 (돌파·되돌림·변동성 돌파·순환 등), 사양서 | 4시간봉 55봉 돌파 + ATR 2배 손절 규칙 고정, 관리자 전용 /coin |
| `dividend/` | 배당락 매매(배당 포착) 검증 | 세후 손실 → 배당락 매매 기능은 만들지 않고 일정·현금흐름 관리만 제공 |

`scripts/research-20261014-*`는 10-14 전략 점검 때 쓴 스크립트입니다 (`docs/strategy-review-20261014.md`).
