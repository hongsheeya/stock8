토스증권 API

토스증권 WTS 설정 > Open API에서 받은 값 중 api key(tsck_...)는 첫 번째 칸, secret key(tssk_...)는 두 번째 칸에 입력합니다. accountSeq는 비워두는 것을 권장합니다.

토스증권 Open API 화면에서 api key라고 표시된 값을 앞뒤 공백 없이 그대로 붙여넣습니다. secret key를 이 칸에 넣으면 안 됩니다.

토스증권 Open API 화면에서 secret key라고 표시된 값을 붙여넣습니다. api key를 이 칸에 넣으면 안 됩니다.
