# 대시보드 손익 카드 균형 재배치·화이트 모드·기본 한글 설정

- **ID**: 009
- **날짜**: 2026-05-28
- **유형**: 기능 추가

## 작업 요약
대시보드 손익 현황 영역을 상단 히어로 카드와 하단 4분할 카드 구조로 재배치해 균형감 있는 그리드로 정리했다.
대시보드 전용 화이트 모드 토글과 저장 기능을 추가했고, 번역 기본값이 저장되지 않은 환경에서는 한국어가 기본 언어가 되도록 조정했다.

## 원문 요청사항
```text
1. 디자인 꼬라지가 저게 맞아? 그리드를 균형감있게 해야지.
2. 화이트 모드도 만들어줘
3. 기본 언어 설정을 한글로 해
```
