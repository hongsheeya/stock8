# 단타 학습 우수 종목 자동 편입

- **ID**: 014
- **날짜**: 2026-05-28
- **유형**: 기능 추가

## 작업 요약
국장 단타 후보 유니버스가 고정 종목 위주라, 이미 학습으로 성과가 검증된 종목이 다음 재학습부터 빠지는 문제가 있었다. 이를 막기 위해 `profile_book.json`에서 검증 수익·검증 일평균 수익·승률·손익비·그래프 안정성을 통과한 종목을 자동으로 후보 유니버스에 다시 편입하도록 개선했다.

이제 기본 후보 리스트에 없는 종목도 한 번 성과가 검증되면 다음 재학습 때 계속 포함된다. 현재 프로필 북 기준으로 기본 후보 밖에서 추가 편입되는 국장 종목은 7개로 확인됐다.

## 원문 요청사항
```text
다른 종목들도 추가로 학습을하고 앞으로 좀 잘해보자
```
