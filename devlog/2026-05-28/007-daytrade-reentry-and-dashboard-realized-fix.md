# 단타 손실 후 재진입 지속 및 대시보드 실현수익 왜곡 보정

- **ID**: 007
- **날짜**: 2026-05-28
- **유형**: 버그 수정

## 작업 요약
국장 단타가 손절 이후 일일 손실 제한 때문에 신규 진입을 사실상 멈추던 동작을 기본적으로 소프트 경고로 전환했다.
대시보드 실현수익 계산에서는 청산되지 않은 FireGate 정리용 완료 사이클을 제외하고, 전체 기간 단타 실현손익은 누적 상태값을 우선 사용하도록 보정했다.

## 원문 요청사항
```text
요즘 장 시작할때 한번에 종목 엄청 많이 사고 그거 다 손절때리고 추가로 더 진입을 안하는거야? 아니 계속 돌리라고 왜 멈추냐고. 손해봤으면 복구해야지

실현 수익 왤케 더무니없이 120만원 찍히는건데 어디서 꼬인거야. 좀 제대로 된 값난 표시하라고
```

## 변경 파일 목록
- 단타 엔진
  - `src/portal/trading/model/struct/daytrade_engine.py`
    - 일일 손실 제한을 기본적으로 소프트 경고로 처리하고, `daytrade_daily_loss_halt_enabled=true`일 때만 신규 진입 하드 차단이 걸리도록 변경
    - 손절 후 당일 재진입 종일 차단 기본값을 해제하고 쿨다운 기반 재진입으로 유지
- 대시보드 집계
  - `src/app/page.dashboard/api.py`
    - 청산되지 않은 완료 사이클을 실현손익 집계에서 제외
    - 전체 기간 단타 실현손익은 daytrade 상태 누적 실현손익을 우선 사용하도록 보정
- 테스트
  - `tests/test_daytrade_engine_regressions.py`
    - 일일 손실 제한 소프트 경고 및 손절 후 재진입 기본 정책 회귀 테스트 추가
  - `tests/test_dashboard_accounting_regressions.py`
    - 완료 사이클 실현손익 포함/제외 기준 회귀 테스트 추가
