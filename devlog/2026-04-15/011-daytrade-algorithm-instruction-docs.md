# 단타 알고리즘/학습 규칙 인스트럭션 문서화

- **ID**: 011
- **날짜**: 2026-04-15
- **유형**: 문서 업데이트

## 작업 요약
`/daytrade`에서 실제로 사용하는 학습·추천·실시간 진입/청산·자동순환 로직을 코드 기준으로 다시 정리했다. 코어 인스트럭션이 아니라 커스텀 문서 우선 원칙에 맞춰 `.github/custom/algorithm-daytrade.md`, `.github/custom/daytrade-usage.md`에 입력값, 점수 기준, 시드 용어, 캐시 정책, 후보 제외 사유를 구체화했다.

## 변경 파일 목록
### 문서
- `.github/custom/algorithm-daytrade.md`
  - 학습 파이프라인, 추천 점수 계산, 실시간 진입/청산 조건, 자동 교체 로직을 실제 코드 흐름 기준으로 정리
  - `requested_seed`, `training_seed`, `price_cap_krw`, 캐시 키, stale refresh 정책을 문서에 반영
- `.github/custom/daytrade-usage.md`
  - 시드 변경 시 후보/추천이 어떻게 재구성되는지, 장중 추천이 언제 갱신되는지, 후보가 사라지는 것이 정상 제외인지 버그인지 구분하는 기준을 추가

## 검증
- 문서 내용이 최신 백엔드/프론트 수정 방향과 일치하도록 용어를 정리
- 단타 관련 설명 문서를 커스텀 인스트럭션 우선 원칙에 맞춰 유지
