# 단타 자동 손절 분봉 저가 꼬리 오발동 보정

- **ID**: 004
- **날짜**: 2026-04-22
- **유형**: 버그 수정

## 작업 요약
실제 매도 로그를 점검한 결과, 당일 수백 원 수준의 청산 다수는 잭팟/방어/구조 청산이 아니라 `SELL_STOP_LOSS`로 발생하고 있었다. 원인은 1분봉 `low`가 자동 손절가를 한번 찍기만 해도, 현재가가 이미 회복되어 평균단가 위에 있어도 자동 손절로 확정되는 로직 때문이었다.

## 변경 파일 목록
### 단타 엔진
- `src/portal/trading/model/struct/daytrade_engine.py`
  - 자동 손절은 `current_price <= auto_stop_price`일 때 즉시 발동한다.
  - 분봉 저가 꼬리 터치만 있는 경우에는 `current_price <= break_even_price`일 때만 자동 손절로 인정하도록 보수화했다.
  - pending 지정가 매도 취소 후 손절 우선 실행 조건에도 동일한 자동 손절 판정을 적용했다.
  - 자동 손절 이유 문구를 `자동 손절가 확인`으로 조정했다.

## 검증
- 2026-04-22 매도 로그를 조회해 수백 원 수준 청산 다수가 `SELL_STOP_LOSS`였음을 확인했다.
- 일반 빌드를 수행해 변경 사항이 정상 반영되는 것을 확인했다.
