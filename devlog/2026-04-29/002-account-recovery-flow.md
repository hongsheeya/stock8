# 회원 아이디/비밀번호 찾기 구현

- **ID**: 002
- **날짜**: 2026-04-29
- **유형**: 기능 추가

## 작업 요약
이름·휴대폰 번호 기반 아이디 찾기와 이메일·이름·휴대폰 번호 기반 비밀번호 재설정 기능을 로그인 페이지에 추가했다. 기존 사용자 스키마의 `mobile` 필드를 활용해 추가 DB 마이그레이션 없이 복구 흐름을 연결했다.

## 변경 파일 목록
### 백엔드
- `src/model/struct/user.py` — 이메일 조회, 아이디 찾기, 본인확인 기반 비밀번호 재설정 메서드 추가
- `src/app/page.access/api.py` — `find_id`, `reset_password`, 모바일 정규화/이메일 마스킹 처리 추가

### 프론트엔드
- `src/app/page.access/view.ts` — 아이디 찾기/비밀번호 재설정 상태와 액션 추가
- `src/app/page.access/view.pug` — 로그인 하단 진입 링크, 회원가입 모바일 입력, 복구 UI 추가

### 검증
- 타입/템플릿 진단 오류 확인
- 프로젝트 빌드로 접근 페이지 렌더링 검증
