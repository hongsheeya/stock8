# 미장 단타 실거래 동작 검증 API 추가

- **ID**: 014
- **날짜**: 2026-04-29
- **유형**: 기능 추가

## 작업 요약
미장 단타 실행 경로를 주문 전송 없이 점검할 수 있는 검증 API를 추가했다.
KIS 연결, 후보 유니버스, 신호 생성, 일일 로그 접근 상태를 체크하고 승률/체결/잔여포지션 지표를 계산해 반환한다.

## 변경 파일 목록
- `src/app/page.daytrade/api.py`
  - `us_verify_runtime()` 신규 추가
    - 점검 항목(`checks`) 반환
    - 결과 요약(`metrics`) 반환: 체결 건수, 잔여 포지션, 승/패, 승률, 자동매매 상태
    - `ok` 플래그 및 `kis_status`, `status` 포함
