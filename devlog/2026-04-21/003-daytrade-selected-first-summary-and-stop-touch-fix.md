# 단타 당일요약 매칭 우선순위 및 손절 터치 감지 보정

- **ID**: 003
- **날짜**: 2026-04-21
- **유형**: 버그 수정

## 작업 요약
당일 거래 요약이 전체 히스토리를 FIFO로 그대로 매칭하면서, 오래된 미정리 carry lot가 당일 매수보다 먼저 소비되어 두산에너빌리티의 매수 금액이 잘못 표시되고 있었다.
또한 손절은 폴링 시점의 현재가만 비교하고 있어, 15초 주기 감시 사이에 가격이 손절가를 찍고 반등하면 매도가 발생하지 않는 문제가 있었다.

## 변경 파일 목록
### 거래 일지 API
- `src/app/page.daytrade/api.py`
  - 당일 거래 요약에서 당일 매수 lot를 먼저 매칭하고, 부족한 수량만 carry lot로 연결하도록 변경했다.
  - 이로써 당일 매수/매도 요약은 선택일 거래 기준으로 표시되고, carry는 실제 부족분에만 반영된다.

### 단타 엔진
- `src/portal/trading/model/struct/daytrade_engine.py`
  - 손절 판단 기준에 `current_price`뿐 아니라 현재 분봉의 `low` 터치 가격도 반영하도록 수정했다.
  - pending 지정가 매도 대기 중에도 손절 터치가 발생하면 취소 후 손절을 우선 실행하도록 동일 기준을 적용했다.

### 검증
- trade_log 직접 조회로 두산에너빌리티(`034020`)가 당일 2주 `114,300` 매수 후 2주 매도된 것을 확인했다.
- 선택일 우선 매칭 시 매수 금액이 `228,600`, carry 금액이 `0`으로 계산됨을 별도 스크립트로 검증했다.
- WIZ 프로젝트 일반 빌드를 수행해 변경 사항이 정상 반영되는 것을 확인했다.
