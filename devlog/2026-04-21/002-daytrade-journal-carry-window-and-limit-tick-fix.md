# 단타 일지 carry 오매칭 및 지정가 호가단위 오류 수정

- **ID**: 002
- **날짜**: 2026-04-21
- **유형**: 버그 수정

## 작업 요약
당일 거래 일지의 빠른 요약 경로가 최근 500건 로그만 사용하면서 오래된 매수 lot만 남고 대응 매도가 누락되어, 두산에너빌리티처럼 전일 carry가 아닌 체결까지 carry로 잘못 매칭되는 문제가 있었다.
또한 잭팟 사전예약 지정가 매도가 한국 주식 호가단위를 맞추지 않은 가격으로 전송되어 LIMIT 주문이 거절되는 문제가 있어, 지정가 가격 정규화를 함께 보강했다.

## 변경 파일 목록
### 거래 일지 API
- `src/app/page.daytrade/api.py`
  - 빠른 일지 요약용 로컬 거래 로그 조회 범위를 500건에서 5000건으로 확대하여 오래된 미정리 lot가 잘못 carry로 잡히는 가능성을 줄였다.

### 단타 엔진
- `src/portal/trading/model/struct/daytrade_engine.py`
  - 원화 호가단위 반올림을 가격대별 tick 규칙에 맞게 수정했다.
  - `PRE_SELL_JACKPOT` 지정가 주문 시 정규화된 호가 가격을 사용하도록 변경했다.

### 검증
- WIZ 프로젝트 일반 빌드를 수행해 변경 사항이 정상 반영되는 것을 확인했다.
