# 국장 단타 거래일지 브로커 우선 병합 규칙 수정

- **ID**: 009
- **날짜**: 2026-05-04
- **유형**: 버그 수정

## 작업 요약
국장 단타 거래일지가 실제 거래내역과 계속 어긋난 근본 원인을 재추적한 결과, 브로커 동기화가 켜져 있어도 선택 기간의 로컬 `trade_log` 체결 행을 그대로 먼저 병합하고 있어 KIS 실체결과 맞지 않는 로컬 주문 로그가 화면에 남는 구조였다.
브로커 조회가 성공한 시장의 선택 기간 체결은 로컬 로그를 억제하고 브로커 체결만 표시하도록 병합 규칙을 수정해, 국장 단타 거래일지가 실제 체결 내역을 기준으로 표시되도록 보정했다.

## 원문 요청사항
```text
아니 그게 중요한게 아니라 실제 거래 내역이랑 표시된 거래일지랑 안맞는다고. 원인 찾아서 고치라고. 뭔 갑자기 fallback을 점검하는건데. 국장 단타 거래일지 실제 거래내역과 동기화 시키고 앞으로 문제 없도록 제대로 수정해
```
