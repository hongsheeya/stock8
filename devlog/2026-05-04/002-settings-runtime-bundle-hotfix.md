# 설정 페이지 런타임 번들 직접 패치로 프런트 예외 처리 반영

- **ID**: 002
- **날짜**: 2026-05-04
- **유형**: 버그 수정

## 작업 요약
빌드 파이프라인이 프로젝트 전역 TypeScript 오류로 막혀 설정 페이지 프런트 수정이 런타임 번들에 반영되지 않던 문제를 확인했다.
실제 서비스에 사용되는 `bundle/www/main.js`를 최소 범위로 직접 패치해 `load_settings` 실패 시 예외를 잡고, 사용자에게 에러 배너를 표시하도록 보정했다.

## 원문 요청사항
```text
아직 에러가 고쳐지지 않았어. 모든 에러 검증하고 검토해서 원인 분석하고 다시 안나타나게 제대로 고쳐놔
```

## 변경 파일 목록
### 런타임 번들
- `bundle/www/main.js`
  - 설정 페이지 템플릿에 `loadError` 배너 추가
  - 컴포넌트 초기 상태에 `loadError` 필드 추가
  - `loadSettings()`에서 `wiz.call("load_settings")` 실패/비정상 응답을 `try/catch`로 처리
  - 실패 시 로딩 상태를 정상 해제하고 콘솔 `Uncaught (in promise)`를 방지하도록 보정
