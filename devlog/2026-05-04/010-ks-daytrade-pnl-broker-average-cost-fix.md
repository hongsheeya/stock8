# 국장 단타 매매손익 증권사 기준 정합 보정

- **ID**: 010
- **날짜**: 2026-05-04
- **유형**: 버그 수정

## 작업 요약
국장 단타 거래일지의 매매손익이 실제 투자증권 앱 표시와 어긋난 원인을 재추적한 결과, 기간 거래요약이 국내 체결을 FIFO 기준으로 재매칭하고 하드코딩된 수수료를 다시 가산하고 있었다.
국장 거래일지 손익 계산을 증권사 화면과 맞도록 평균단가 기반으로 재계산하고, 수수료도 프로필 기반으로 계산하도록 수정해 실체결 손익과 표시 손익의 정합성을 보정했다.

## 원문 요청사항
```text
아니 ㅅㅂ 실제 투자증권에서 표시하는 매매손익이랑 안맞는다고. 원인 좀 ㅅㅂ 제대로 찾아내서 고쳐봐. 너 뭐가 문제야
```
