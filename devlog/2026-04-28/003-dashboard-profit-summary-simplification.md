# 대시보드 수익 요약 통합 및 간소화

- **ID**: 003
- **날짜**: 2026-04-28
- **유형**: 기능 추가

## 작업 요약
대시보드 수익 요약 API에 단타 손익 집계를 포함하도록 확장했다. 대시보드 화면은 전체 수익 현황 중심으로 간소화하고, 상세 운영 화면은 별도 서브페이지로 이동할 수 있도록 바로가기 카드를 추가했다.

## 변경 파일 목록
### 대시보드 백엔드
- `src/app/page.dashboard/api.py`: import 시점 디버그 잔재 제거, `profit_summary()`에 단타 실현/미실현 손익 및 거래 건수 집계 추가, 자산 스냅샷에 단타 누적 손익 반영

### 대시보드 프론트엔드
- `src/app/page.dashboard/view.ts`: 단타 손익 필드 기본값 추가, 레거시 상세 섹션 토글 상태 추가, 초기 로드에서 거래 프리뷰 호출 제거
- `src/app/page.dashboard/view.pug`: 수익 카드에 단타 지표 노출, Daytrade/History/Simulation/Settings 바로가기 카드 추가, 기존 무한매수 상세 섹션 숨김 처리

### 검증
- 파일 오류 검사 통과
- 프로젝트 일반 빌드(`clean: false`) 성공
