# 설정 화면 실사용 HTML 토글에도 단타 경고 팝업 직접 반영

- **ID**: 005
- **날짜**: 2026-06-11
- **유형**: 버그 수정

## 작업 요약
설정 화면이 실제로 사용하던 `view.html`에도 단타 토글 클릭 핸들러를 직접 반영했다.
이제 설정 탭에서 국내/미장 단타 토글을 켤 때 즉시 경고 팝업이 뜨고, 기존의 직접 boolean 반전 경로는 제거됐다.

## 원문 요청사항
```text
ㅅㅂ 3번째 얘기하는거다. 저거 토글 킬 때 경고문 팝업으로 표시해라
```

## 변경 파일 목록
- `src/app/page.settings/view.html`
  - 국내/미장 단타 토글 클릭을 즉시 경고 메서드로 교체
  - OFF 안내 문구를 무동작 설명으로 교체
