# 단타 OFF→ON 전환 경고 모달 추가

- **ID**: 003
- **날짜**: 2026-06-11
- **유형**: 버그 수정

## 작업 요약
단타 자동매매를 OFF 상태에서 다시 켤 때 즉시 실행 위험을 명확히 인지할 수 있도록 경고 확인 모달을 추가했다.
국장 단타, 미장 단타, 설정 저장, 대시보드 단타 자동화 카드 경로에서 OFF→ON 전환 전에 확인을 요구하도록 정리했다.

## 원문 요청사항
```text
그니까 상식적으로 off를 하면 그거는 다 막아야지 2차 차단이 없다고 하는거는 미친거 아니야? 처음부터 잘 막아야지. 너 떄문애 20만원 손해봤잖아. 왠만한 사람들은 단타 사용 안할거니까 on/off 잘 구분 안해놓으면 안돼. off에서 on으로 킬때 경고문 넣어놔
```

## 변경 파일 목록
- `src/app/page.daytrade/view.ts`
  - 국장 단타 자동매매 OFF→ON 전환 전 경고 모달 추가
- `src/app/page.daytrade.us/view.ts`
  - 미장 단타 자동매매 OFF→ON 전환 전 경고 모달 추가
- `src/app/page.dashboard/view.ts`
  - 대시보드 단타 자동화 카드에서 OFF→ON 전환 전 경고 모달 추가
- `src/app/page.settings/view.ts`
  - 설정 저장으로 단타 OFF→ON 전환 시 경고 모달 추가
