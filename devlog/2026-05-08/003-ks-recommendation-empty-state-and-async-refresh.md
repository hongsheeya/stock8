# 국장 추천 비표시 원인 보정 및 비동기 추천 갱신 추가

- **ID**: 003
- **날짜**: 2026-05-08
- **유형**: 버그 수정

## 작업 요약
국장 단타 페이지에서 추천 객체는 존재하지만 `leaderboard`가 비어 있을 때 화면이 아무 것도 표시하지 않던 상태를 보정했다.
초기 렌더는 가볍게 유지하면서, 추천 캐시가 비어 있거나 만료된 경우 첫 렌더 직후 비동기로 `recommend`를 다시 호출해 종목 추천이 자동으로 채워지도록 변경했다.

## 원문 요청사항
```text
국장 종목 추천이 계속 표시가 안되는데 이것때문에 안좋은 종목만 구매하는거 같은데 원인 좀 잡아서 종목 좀 제대로 표시하게 해. 이것도 너무 무거워서 표시 안되는거야?
```

## 변경 파일 목록
### 프론트엔드
- `src/app/page.daytrade/view.ts`
  - 추천 랭킹이 비어 있으면 첫 렌더 직후 백그라운드로 추천을 다시 가져오는 `refreshRecommendationIfMissing()` 추가
  - 추천 비어 있음 상태 사유 표시용 `recommendationEmptyReason` getter 추가
  - 초기화 흐름에 추천 비동기 갱신 큐 추가
- `src/app/page.daytrade/view.pug`
  - `recommendation` 객체는 있지만 `leaderboard`가 비어 있는 경우도 빈 상태 카드가 보이도록 조건 수정
  - 수동 추천 갱신 버튼과 원인 문구 추가

### 빌드 미러
- `build/src/app/page.daytrade/page.daytrade.component.ts`
  - 런타임 반영용 동일 변경 동기화
- `build/src/app/page.daytrade/view.pug`
  - 빈 상태/갱신 버튼 UI 동기화

## 원인 정리
- 추천 비표시는 단순 렌더링 지연만의 문제는 아니었다.
- 초기 부트스트랩은 성능을 위해 캐시 기반 추천만 읽도록 가벼워졌는데, 캐시가 비어 있거나 `leaderboard`가 빈 추천 객체가 오면 템플릿에서 `!recommendation` 조건이 거짓이어서 시작 카드도 안 보이고 랭킹도 안 보였다.
- 이번 수정으로 빈 추천 상태를 명시적으로 보여주고, 첫 렌더 후 비동기 재추천을 자동 수행하도록 보완했다.
