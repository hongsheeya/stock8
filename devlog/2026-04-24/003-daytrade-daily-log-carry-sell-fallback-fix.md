# 단타 일지 carry 매도 누락 fallback 보정

- **ID**: 003
- **날짜**: 2026-04-24
- **유형**: 버그 수정

## 작업 요약
당일 일지는 빠른 로컬 요약 경로(`_quick_daily_log_summary`)를 우선 사용하고 있었는데, 이 경로가 최근 5,000건 로그만 읽고 현재 live_state를 보조 정보로 사용하면서 이전 날짜 매수분이 오늘 매도된 경우 FIFO 매칭이 완전히 복원되지 않는 문제가 있었다. 특히 이미 청산된 종목은 live_state의 `avg_price`가 0으로 초기화되어, carry 매도인데도 `matched_qty`가 0이 되어 일지 요약/사이클 목록에서 빠질 수 있었다.

이에 당일 빠른 일지에서도 로그 조회 범위를 20,000건으로 늘리고, 오늘 매도 중 FIFO 매칭이 전량 복원되지 않은 건이 하나라도 있으면 즉시 전체 기간 집계(`period_trade_summary`)로 fallback 하도록 보정했다. 이로써 이전에 사서 오늘 판 건도 다시 일지에 빠지지 않도록 수정했다.

## 변경 파일 목록
### 일지 API
- `src/app/page.daytrade/api.py`
  - 빠른 일지 로그 조회 범위를 5,000건 → 20,000건으로 확대
  - 당일 매도의 FIFO 매칭이 0건 또는 부분 매칭이면 전체 집계로 자동 fallback
