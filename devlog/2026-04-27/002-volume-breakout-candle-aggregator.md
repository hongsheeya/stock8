# Volume Breakout: 장중 캔들 조립 계층 구현

- **ID**: 002
- **날짜**: 2026-04-27
- **유형**: 기능 추가

## 작업 요약
'volume_breakout' 전략의 데이터 신뢰성을 높이기 위해, 실시간 체결 데이터를 기반으로 1분봉 OHLCV를 직접 조립하는 'Candle Aggregator' 계층을 구현했습니다. 이를 통해 KIS API에서 제공하는 현재가 정보의 지연 문제를 보완하고, 더 정확한 시점의 데이터를 신호 생성에 활용할 수 있게 되었습니다.

## 변경 파일 목록

### 1. Model 수정 ()
- ** 메서드 추가**:
  - 종목코드를 받아 내부 캐시()에 저장된 최근 체결 틱 데이터를 사용해 1분 단위 캔들(시/고/저/종/거래량)을 조립합니다.
  - 틱 데이터가 없거나 오래된 경우, KIS API의 를 호출하여 최신 데이터를 가져옵니다.
  - 캔들 데이터는 5분 TTL을 갖는 캐시에 저장하여 불필요한 API 호출을 최소화합니다.
- ** 메서드 수정**:
  - 기존에 으로 KIS 데이터를 가져온 직후, 을 호출합니다.
  - 유효한 집계 캔들이 반환되면,  객체를 해당 데이터로 덮어쓰고 를 'agg_candle'로 명시하여 데이터 출처를 추적할 수 있도록 했습니다.
  - 이를 통해 신호 생성 로직의 나머지 부분은 변경 없이 향상된 데이터 소스를 사용하게 됩니다.
