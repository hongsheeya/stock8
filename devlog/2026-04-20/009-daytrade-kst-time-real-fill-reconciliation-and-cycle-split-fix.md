# 단타 일지 KST 시간, 실체결가 보정, 구매 사이클 분리 복구

- **ID**: 009
- **날짜**: 2026-04-20
- **유형**: 버그 수정

## 작업 요약
당일 일지에서 시간이 UTC 기준으로 9시간 밀려 보이고, 실제 KIS 체결가 대신 내부 추정가가 기록되어 손익이 어긋나며, 동일 종목의 매수-매도-재매수 흐름이 하나의 종목 요약으로 합쳐지던 문제를 수정했다.
당일 요약 API에서 한국시간 기준으로 로그 시각을 정규화하고, KIS 당일 체결내역으로 실체결가를 보정하며, 종목별 요약은 구매 사이클 단위로 분리해 표시하도록 변경했다.

## 변경 파일 목록
- `src/app/page.daytrade/api.py`
  - 당일 거래 로그 시간을 KST로 변환해서 필터링/표시하도록 수정
  - `trade_log` 행을 KIS 당일 체결내역과 `order_no`로 매칭해 실제 체결가/체결수량으로 보정
  - 종목별 거래 요약을 심볼 합산이 아니라 `사이클 #n` 단위로 분리 생성
- `src/app/page.daytrade/view.pug`
  - 종목별 거래 요약에 사이클 라벨 표시 추가
- `src/portal/trading/model/struct/daytrade_engine.py`
  - 신규 주문 로그 저장 시 KIS 실체결가/실체결수량을 우선 반영하도록 보강
  - 손익 계산과 로그 메시지를 추정 현재가가 아닌 실제 체결가 기준으로 기록하도록 수정
- `devlog.md`
  - 작업 이력 추가
