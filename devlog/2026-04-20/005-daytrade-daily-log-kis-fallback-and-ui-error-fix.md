# 단타 거래 일지 KIS fallback 및 UI 오류 표시 복구

- **ID**: 005
- **날짜**: 2026-04-20
- **유형**: 버그 수정

## 작업 요약

- 거래 일지가 보이지 않던 원인을 점검한 결과, 기간/당일 일지 집계가 KIS 체결내역 조회 실패 시 전체 API를 실패시키는 구조였고, 프론트엔드에서는 해당 오류를 조용히 무시하고 있었음.
- 이로 인해 로컬 거래 로그가 존재해도 일지 패널이 빈 것처럼 보일 수 있었음.

## 변경 파일 목록

### 1. KIS 실패 시 로컬 로그 fallback
- `src/portal/trading/model/struct/daytrade_engine.py`
  - `period_trade_summary()`에서 KIS 거래내역 조회 실패 시 전체 실패하지 않고 `broker_fills=[]`로 계속 집계하도록 수정
  - 런타임 로그에 `거래 일지 KIS 동기화 실패 — 로컬 로그 기준으로 계속 표시합니다` 경고를 남기도록 추가

### 2. UI 오류 표시 복구
- `src/app/page.daytrade/view.ts`
  - `loadDailyLog()`가 실패 코드를 무시하지 않고 `errorMessage`를 표시하도록 수정
  - 예외 발생 시에도 silent 처리하지 않고 사용자에게 오류를 노출하도록 수정

## 검증 내용

- 빌드 성공
- 번들에 `거래 일지 KIS 동기화 실패 — 로컬 로그 기준으로 계속 표시합니다` 반영 확인
- 백엔드 자식 프로세스 재기동 완료
  - 스레드 수: 3
  - FD 수: 27

## 결론

- 일지가 안 보이던 직접 원인은 `KIS 조회 실패 = 일지 전체 실패` 구조와 프론트엔드의 silent catch 조합이었음.
- 수정 후에는 KIS가 일시 실패해도 로컬 거래 로그 기준으로 일지가 계속 표시되며, 진짜 오류가 나면 화면에도 메시지가 보이도록 복구함.
