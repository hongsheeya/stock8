# 국장 장마감 시드 확보용 저율 익절 기준 추가

- **ID**: 006
- **날짜**: 2026-05-12
- **유형**: 전략 조정

## 작업 요약
국장 단타 `vrev` 보유 종목이 장 마감 직전 오버나잇 조건을 만족하더라도, 기존보다 낮은 수익률만 확보되면 전량 청산해 미장 단타용 시드를 회수할 수 있도록 조정했다.
기본 장마감 시드 확보 익절 기준을 `+0.4%`로 추가했고, 이 경우 잭팟 우선 홀드 가드에 막히지 않도록 예외 플래그를 넣었다. 기존 미세 익절 방지 로직은 그대로 살아 있어 수수료만 겨우 넘기는 수준의 작은 이익은 계속 보류된다.

## 원문 요청사항
```text
장 마감 전에 수수료보다 이득이면 적당히 그냥 팔아. 그 시드를 확보해야 미장 단타에 사용할 수 있잖아. 그렇다고 100원 먹겠다고 팔지는 말고 기존보다 %만 낮춰
```

## 변경 파일 목록
- `src/portal/trading/model/struct/daytrade.py`
  - `close_liquidity_take_profit_pct` 기본값 `0.4` 추가.
- `src/portal/trading/model/struct/daytrade_engine.py`
  - 장마감 임박 시 `vrev` 보유 종목이 `+0.4%` 이상이면 `SELL_FULL`로 시드 확보 익절하도록 추가.
  - 이 익절은 `ignore_jackpot_soft_guard` 플래그로 잭팟 우선 홀드 가드 예외 처리.
  - 기존 `min_exit_net_profit_krw`, `min_exit_fee_multiple` 기반 미세 익절 방지 로직은 유지.

## 검증
- `python3 -m py_compile`로 변경 파일 문법 검증 완료.
- VS Code 문제 패널 기준 변경 파일 오류 없음 확인.
