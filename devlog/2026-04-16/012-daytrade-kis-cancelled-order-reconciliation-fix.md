# 단타 KIS 취소 주문 정합성 및 거래일지 실체결 우선 보정

- **ID**: 012
- **날짜**: 2026-04-16
- **유형**: 버그 수정

## 작업 요약
KIS 실체결 데이터를 직접 대조한 결과, 금호석유화학 주문 중 일부는 로컬 로그에는 체결로 남아 있었지만 KIS에서는 무체결 취소 주문으로 내려오고 있었다. 이 때문에 기간 거래일지에서 실제 1회 매도만 있었던 종목이 2회 매도처럼 보이고 손익도 왜곡되고 있었다.
병합 키를 `symbol + action + order_no` 기준으로 다시 정리하고, KIS가 무체결/취소로 내려준 주문 번호와 일치하는 로컬 체결 로그는 기간 요약에서 제거하도록 보정했다.

  - KIS 무체결·취소 주문과 일치하는 로컬 체결 로그를 기간 요약에서 제거하도록 보정
  - KIS 실체결 수량이 있는 주문은 실체결 값으로 우선 반영되도록 정리
