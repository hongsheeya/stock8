# 미장 단타 KRW 시드 통일 및 랭킹 테스트 범위 확장

- **ID**: 012
- **날짜**: 2026-05-11
- **유형**: 기능 추가

## 작업 요약
미장 단타 페이지의 시드 입력·저장·검증 기준을 원화(KRW) 기준으로 통일했다. 동시에 모델 랭킹 분석 시 테스트 종목 수를 늘리고 현재 선택 심볼을 포함한 분산 샘플링으로 더 넓은 후보군을 비교하도록 보강했다.

## 원문 요청사항
```text
미장 모델 테스트 제대로 좀 해줘. 종목 더 많이 해보고 더 좋은 알고리즘 계속 찾아내봐.

미장 단타 시드 달러처럼 입력받는데 남은 시드에 원화로 표시되어있어. 입력받ㄴ느것도 원화인지 제대로 확인하고 기준을 다 원화로 해보자
```

## 변경 파일 목록
- **미장 API**
  - `src/app/page.daytrade.us/api.py`
    - 미장 시드를 KRW 기준으로 정규화하는 공통 파서/보정 로직 추가
    - 시드 미입력 시 저장된 미장 기본 시드를 따르도록 기본값 정렬
    - 랭킹 테스트 종목 수를 기본 12개, 최대 18개까지 확장
    - 현재 선택 심볼과 핵심 종목을 우선 포함한 분산 샘플링으로 후보군 선정 개선
    - 검증 문구를 KRW 우선 기준으로 정리
- **미장 화면 로직**
  - `src/app/page.daytrade.us/view.ts`
    - 프론트 기본 시드를 5,000,000 KRW로 조정
    - 랭킹 분석 요청 시 현재 심볼과 확장된 종목 수를 함께 전달
- **미장 화면 UI**
  - `src/app/page.daytrade.us/view.html`
    - 시드 입력 라벨을 KRW 기준으로 명시
    - 상단 예산 카드와 남은 시드 표기를 KRW 기준으로 재정렬
    - 랭킹 패널에 테스트 종목 수 확대 사실을 표시

## 검증
- `wiz project build --project=main`
- 관리자 세션으로 `us_bootstrap`, `us_snapshot`, `us_model_ranking` 호출
  - 저장된 KRW 기본 시드(400000)가 bootstrap/snapshot에 일관되게 반영됨 확인
  - 랭킹 API가 `symbol_count=12`, `focus_symbol=TQQQ`로 응답함 확인
