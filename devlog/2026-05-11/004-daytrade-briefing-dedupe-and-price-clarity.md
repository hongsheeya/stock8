# 단타 브리핑 중복 제거와 매매 가격 안내 강화

- **ID**: 004
- **날짜**: 2026-05-11
- **유형**: 기능 추가

## 작업 요약
단타 투자자용 자동매매 브리핑에서 주문 파라미터 문자열처럼 보이는 저수준 문구를 제거하고, 중지/오류 브리핑의 중복 항목을 한 번만 보이도록 정리했다.
또한 오류 브리핑 위치를 자동매매 브리핑 아래로 이동하고, 종목 코드를 가능한 한 종목명으로 치환하며, 현재 진입/청산이 어느 가격대에서 이뤄질지 요약 카드에서 바로 읽을 수 있도록 보강했다.

## 원문 요청사항
```text
(qty=2, price=0, order_type=MARKET, ord_dvsn=01)
이런 부분들 삭제하는게 나을거 같고 중지 오류 브리핑에서 중복된 사항은 한번만 표시해줘. 그리고 오류 브리핑 위치를 자동매매 브리핑 아래로 옮겨줘
또 종목 표시할때 종목 번호가 아닌 종목명으로 표시해. 자동매매 브리핑에서  언제 매매할건지 정확한 금액도 표시하면 좋을거 같아 
```

## 변경 파일 목록
### 투자자용 자동매매 브리핑 정리
- `src/app/page.daytrade/view.ts`
  - 주문 파라미터 문자열(`qty=...`, `price=...`, `order_type=...`, `ord_dvsn=...`) 제거용 텍스트 정리 헬퍼 추가
  - 중복 오류 항목 제거용 `uniqueRuntimeErrors` 추가
  - 종목 코드를 종목명으로 치환하는 표시 헬퍼 추가
  - 현재 진입/청산 가격과 예상 금액을 보여주는 요약 문구 추가
- `src/app/page.daytrade/view.pug`
  - 오류 브리핑을 자동매매 브리핑 아래로 재배치
  - 오류 브리핑 반복 항목을 중복 제거된 목록으로 변경
  - 로그 카드의 종목 코드 직접 노출 제거
  - `지금 판단` 카드에 진입/청산 가격 요약 추가
