# 단타 화면에서 고급 패널 UI 비노출 처리

- **ID**: 005
- **날짜**: 2026-05-11
- **유형**: 기능 추가

## 작업 요약
사용자 요청에 따라 국내 단타 화면에서 피처 스냅샷, 분석 요약, 현재 보유 포지션, 사용자 지정 가격, 청산 조건 영역을 화면에서 보이지 않도록 제거했다.
백엔드 데이터와 기능 자체는 유지하고, UI에서만 감춰 사용자가 핵심 브리핑과 랭킹 위주로 보도록 정리했다.

## 원문 요청사항
```text
피처 스냅샷, 분ㅓㄱ요약, 현보유포지션, 사ㅇ자 지정 가격, 청산조건  부분 사용자한테 안보이게 기능은 유지하되 UI에서 삭제해줘
```
