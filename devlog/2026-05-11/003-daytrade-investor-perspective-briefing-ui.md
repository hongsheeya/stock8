# 단타 자동매매 브리핑을 투자자 관점 문구로 정리

- **ID**: 003
- **날짜**: 2026-05-11
- **유형**: 기능 추가

## 작업 요약
국내 단타 화면의 자동매매 알림 영역을 투자자 입장에서 바로 이해할 수 있도록 정리했다.
기존 엔진 중심 문구를 줄이고 `지금 판단`, `위험 해석`, `투자자 액션` 요약 카드와 브리핑형 제목/설명으로 바꿔, 왜 대기 중인지와 지금 무엇을 보면 되는지를 더 직접적으로 읽을 수 있게 했다.

## 원문 요청사항
```text
투자자 관점으로 더 정리해서 표시해줘
```

## 변경 파일 목록
### 투자자 관점 요약 문구
- `src/app/page.daytrade/view.ts`
  - `investorDecisionLabel()`, `investorDecisionSummary()`, `investorRiskSummary()`, `investorNextStep()` 추가
  - 전략 이름/로그 제목/설명/칩 문구를 투자자 친화적으로 재정리
  - 기존 운영 로그 메시지를 자금, 대기, 진입/보류 해석 중심 문구로 보정

### 투자자용 브리핑 UI
- `src/app/page.daytrade/view.pug`
  - 실시간 시그널 아래에 `지금 판단`, `위험 해석`, `투자자 액션` 3개 요약 카드 추가
  - `자동매매 알림판`을 `투자자용 자동매매 브리핑`으로 변경
  - `최근 오류/중지 사유`, `최근 자동매매 알림` 제목을 브리핑형 표현으로 변경

- 수정 파일 오류 검사 통과
