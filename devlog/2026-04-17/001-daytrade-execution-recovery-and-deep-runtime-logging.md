# 단타 실주문 복구 및 상세 런타임 로그 보강

- **ID**: 001
- **날짜**: 2026-04-17
- **유형**: 버그 수정

## 작업 요약
`/daytrade`의 매수·매도·자동청산 경로를 전수 점검한 결과, 엔진 클래스에서 `execute_live()`, `execute_exit_watch()`, `_log_execution()` 메서드가 누락되어 실제 주문 경로가 끊겨 있었다. 또한 매수 가드레일이 종목별 배정 시드를 전체 포트폴리오 한도로 잘못 사용해, 신규 매수가 지속적으로 `여유 시드 한도 초과`로 차단되던 문제도 함께 수정했다.

운영 확인을 쉽게 하기 위해 자동순환/실주문/자동청산 경로의 판단 근거를 런타임 로그에 상세 메타와 함께 남기도록 확장했고, 화면에서는 예산 초과 종목도 숨기지 않고 그대로 보이게 바꿨다.

## 변경 파일 목록

### 백엔드
- `src/portal/trading/model/struct/daytrade_engine.py`
  - 누락된 `execute_live()`, `execute_exit_watch()`, `_log_execution()` 복구
  - 수동 전량 매도 후 상태 플래그 초기화 보강
  - 매수 가드레일의 포트폴리오 한도 계산을 총 단타 시드 기준으로 수정
  - 자동순환/실행/자동청산 판단 메타를 상세 런타임 로그로 기록하도록 확장
  - 최근 로그 보존량 및 응답 포함 개수 확대

### 프론트엔드
- `src/app/page.daytrade/view.ts`
  - 예산 초과 종목도 랭킹에서 계속 보이도록 변경
  - 런타임 로그 메타 문자열 렌더링 헬퍼 추가
- `src/app/page.daytrade/view.pug`
  - 예산 초과 배지 및 설명 표시 추가
  - 최근 운영 로그를 더 많이 보여주고 메타 정보까지 노출

## 검증
- WIZ 일반 빌드 성공 (`clean: false`)
- AST 기준 엔진 클래스에 `execute_live`, `execute_exit_watch`, `_log_execution` 메서드 존재 확인
- 변경 파일 정적 오류 없음 확인
