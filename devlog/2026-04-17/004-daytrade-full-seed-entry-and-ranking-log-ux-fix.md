# 단타 전액 진입 허용 및 랭킹/로그 UX 정비

- **ID**: 004
- **날짜**: 2026-04-17
- **유형**: 기능 수정

## 작업 요약
자동매매가 남은 시드를 슬롯 수로 강제로 나누면서 1주 진입 상한이 과도하게 낮아지고, `현재 단타 사용 중 자금이 여유 시드 한도를 초과합니다.` 오류로 실주문이 막히는 문제가 있었습니다.
이번 수정으로 신규 진입은 남은 시드 전액까지 사용할 수 있도록 바꾸고, 랭킹/자동순환/운영 로그 패널이 실제 점검 내용과 가격 정보를 더 자세히 보여주도록 정리했습니다.

## 변경 파일 목록
### 백엔드
- `src/portal/trading/model/struct/daytrade_engine.py`
  - 공유 예산 스냅샷의 `per_symbol_seed_krw`를 남은 시드 전액 기준으로 변경
  - 자동 후보 가격 상한/제외 사유를 `1주 진입 상한` 기준으로 변경
  - 자동순환 신규 진입 시 `remaining_seed_krw` 전액 배정 허용
  - 자동순환 시작/종목 점검/결과 로그를 상세 메타데이터와 함께 기록
  - 자금 초과 HALT를 경고로 완화하여 불필요한 매수 차단 제거
- `src/app/page.daytrade/api.py`
  - 추천 가격 상한 계산을 남은 시드 전액 기준으로 조정

### 프론트엔드
- `src/app/page.daytrade/view.ts`
  - 자동순환 결과 요약/상세 텍스트 헬퍼 추가
  - 랭킹 설명과 워커 판단 문구를 실제 실행/차단/대기 기준으로 보강
  - 즉시 투입 가능 시드 getter를 남은 시드 기준으로 보정
- `src/app/page.daytrade/view.pug`
  - 운영/안전 상태 로그 패널을 랭킹 위로 이동
  - 랭킹 카드에 1주 가격 표시 추가
  - 자동순환 결과 패널에 배정 시드, 주문금액, 차단사유, BUY1 비교 정보 표시
