# 단타 순환후보 등급화 및 일반 사용자용 자동운영 UI 정리

## 배경
- 직전 승률 방어 패치 이후 국장 단타 후보가 `trade_ready` 완전 통과 종목 위주로만 남아 순환 속도가 지나치게 느려졌다.
- 일반 사용자가 매일 봐야 하는 화면에 백테스트, 랭킹, 시드 설명, 전략 파라미터가 너무 많이 노출되어 자동매매 화면의 목적이 흐려졌다.

## 변경
- 단타 후보 품질을 `자동운전(AUTO)`, `순환후보(ROTATE)`, `진입차단(BLOCK)`으로 등급화했다.
- 기대수익/검증수익이 양수이고 손익비·승률의 최소 하한을 넘는 후보는 `ROTATE`로 허용해 빠른 순환을 복구했다.
- 기대수익 또는 검증수익이 음수인 후보, 승률·손익비가 최소 하한 미만인 후보는 계속 차단한다.
- V-REV 라이브 진입 가드를 완화했다.
  - RSI 하한: 36 → 34
  - VWAP 하락 허용폭: 0.45% → 0.65%
  - 개장 직후 대기: 15분 → 8분
  - 매수 간격: 600초 → 360초
  - 2차 매수 대기: 900초 → 600초
- 국장/미장 단타 화면에서 고급 조작을 기본 접힘 처리했다.
- 대시보드 빠른 이동을 자동운영 중심으로 정리하고 일반 사용자에게 불필요한 시뮬레이션 카드를 제거했다.
- 무한매수 화면 설명을 “장 시작 전 LOC 예약매수 1회 + 자동 감시” 흐름으로 바꿨다.
