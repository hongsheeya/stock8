# 단타 변동성 우선 추천 및 무한매수/단타 예산 분리

- **ID**: 011
- **날짜**: 2026-04-10
- **유형**: 기능 추가 + 정책 개선

## 작업 요약
국내 단타 전략이 수수료를 이길 수 있도록 단순 백테스트 점수만 보지 않고 최근 5일 기준 일중 변동폭, 장중 움직임, 유동성을 함께 반영하는 변동성 우선 추천 로직을 추가했다. 또한 미국 무한매수법과 국내 단타가 같은 자금을 임의로 침범하지 않도록, 무한매수의 당일 필요 예약금만 먼저 차감하고 남는 원화만 단타에 사용할 수 있게 예산 분리 정책을 구현했다.

## 변경 파일 목록

### 백엔드
- `src/portal/trading/model/struct/daytrade.py`
  - 최근 5일 5분봉 기준 변동성/유동성 프로파일 계산 추가
  - 추천 랭킹 점수를 `백테스트 점수 + tradability_score` 구조로 개선
  - 추천 결과에 평균 일중 변동폭, 유동성 점수, 선택 사유 포함
- `src/portal/trading/model/struct/daytrade_engine.py`
  - 무한매수 활성 사이클의 당일 필요 예약금(다음 회차 1회분) 계산 추가
  - 원화 출금 가능 금액에서 무한매수 당일 예약금을 차감한 단타 가능 예산 계산 추가
  - 강제매수(force buy) 코드 제거 유지
- `src/app/page.daytrade/api.py`
  - bootstrap/chart_data/live_status/execute_live에 `budget_status` 포함
  - 실제 단타 시드는 `requested_seed`가 아니라 `effective_daytrade_seed`로 캡 처리

### 프론트엔드
- `src/app/page.daytrade/view.ts`
  - budget_status 상태 추가
  - 추천 완료 메시지에 변동성 선택 사유 반영
  - 선택 종목 랭킹 정보 getter 추가
- `src/app/page.daytrade/view.pug`
  - 출금 가능 원화 / 무한매수 당일 예약 / 단타 사용 가능 / 실제 적용 시드 표시
  - 무한매수 당일 예약 내역(종목별 다음 회차 예약액) 표시
  - 랭킹과 백테스트 결과에 평균 일중 변동폭 표시

## 핵심 정책
1. **단타 추천 기준**: 백테스트 수익률만이 아니라 최근 변동성/유동성도 함께 반영
2. **예산 분리 기준**: 무한매수 전체 자금이 아니라 `당일 실제로 필요한 다음 회차 1회분`만 예약
3. **단타 사용 가능 금액**: `출금 가능 원화 - 무한매수 당일 예약금`
4. **실제 주문 시드**: `min(요청 시드, 단타 사용 가능 금액)`
