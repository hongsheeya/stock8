# 단타 차트 고정 높이, 100원 단위 판매가, 판매가/손절가 토글 추가

- **ID**: 013
- **날짜**: 2026-04-10
- **유형**: 버그 수정 + UX 개선 + 기능 추가

## 작업 요약
단타 차트가 새로고침 시 사라졌다가 다시 생기면서 아래 UI가 흔들리던 문제를 수정하기 위해 차트 영역 높이를 고정하고 로딩 오버레이 방식으로 변경했다. 사용자 판매가 조정은 100원 단위 버튼으로 증감 가능하게 바꾸고, 자동 새로고침 중 입력값이 덮어써져 저장이 잘 안 되던 문제를 편집 상태 보호 로직으로 수정했다. 또한 사용자 판매가 On/Off 토글과 손절가 On/Off 토글, 손절가 가격 설정 기능을 추가했다.

## 변경 파일 목록
- `src/app/page.daytrade/view.ts`
  - 자동 새로고침 중 편집 상태 보호
  - 판매가/손절가 토글, 가격 상태, ±100 조정 메서드 추가
- `src/app/page.daytrade/view.pug`
  - 차트 높이 고정 (`h-[320px]`) + 로딩 오버레이 적용
  - 판매가/손절가 토글 UI 및 ±100 버튼 추가
- `src/portal/trading/model/struct/daytrade_engine.py`
  - `manual_sell_enabled`, `stop_loss_enabled`, `stop_loss_price` 상태 추가
  - 손절가 우선 SELL_STOP_LOSS 시그널 추가
- `src/app/page.daytrade/api.py`
  - `update_trade_settings`에서 판매가/손절가 토글 및 가격 함께 저장
  - 차트/청산 계획에 손절가 트리거 반영

## 효과
1. 차트 새로고침 시 레이아웃 흔들림 제거
2. 판매가/손절가 100원 단위 조정 가능
3. 자동 새로고침 때문에 저장이 풀리던 문제 완화
4. 판매가/손절가 각각 독립적으로 켜고 끌 수 있음
