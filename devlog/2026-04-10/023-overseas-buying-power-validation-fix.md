# 해외 매수 주문가능금액 검증을 실제 종목 기준으로 수정

- **ID**: 023
- **날짜**: 2026-04-10
- **유형**: 버그 수정

## 작업 요약
해외 SOXL 매수 실패의 원인이 대시보드 표시 금액과 실제 KIS 해외 주문가능금액 검증 기준이 다르다는 점으로 확인됐다.
이제 해외 주문가능금액 조회는 하드코딩된 TQQQ/NASD/$50 대신 실제 주문 종목/거래소/가격 기준으로 조회하고, 주문 전 최대 가능 수량을 다시 확인하도록 수정했다.

## 변경 파일 목록
- `src/portal/trading/model/struct/kis_api.py`
  - 해외 주문가능금액 조회가 실제 `symbol/exchange/price` 기준으로 동작하도록 수정
  - 매수 주문 전 실제 주문가능수량 부족 시 더 구체적인 오류를 반환하도록 보강
- `src/portal/trading/model/struct/engine.py`
  - 무한매수 주문 직전에 실제 해외 주문가능금액/수량을 다시 조회하고 수량을 보정하도록 수정
- `src/app/page.dashboard/api.py`
  - 대시보드 총 매수 가능액이 KRW 환산치를 합산해 오해를 주지 않도록 USD 주문가능액 기준으로 조정
