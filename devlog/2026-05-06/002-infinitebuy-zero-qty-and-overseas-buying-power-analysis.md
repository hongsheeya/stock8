# 무한매수 0주 주문 차단 및 해외 주문가능금액 0 원인 분석

- **날짜**: 2026-05-06

## 작업 요약
무한매수 1회차에서 분할 투자금이 1주 가격보다 작아도 매수 시도로 내려가던 문제를 수정해 0주 주문을 차단했다.
동시에 KIS 실계좌 설정과 실응답을 점검해, 해외 주문가능수량 0 문제는 계좌 미지원이 아니라 현재 해외 주문가능 외화 금액이 0인 상태임을 확인했다.
