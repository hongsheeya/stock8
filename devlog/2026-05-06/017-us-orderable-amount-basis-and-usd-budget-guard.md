# 미장 주문가능금액 기준 정합 및 USD 예산 가드 보강

- **ID**: 017
- **날짜**: 2026-05-06
- **유형**: 버그 수정

## 작업 요약
미장 단타 주문 경로가 KRW 요청 시드를 그대로 USD 가격에 나누는 방식으로 수량을 계산할 수 있던 문제를 보정했다. 해외주식 매수가능금액조회 결과를 실주문 직전에 다시 검증하도록 바꾸고, UI/검증 API에도 USD 주문가능금액과 참고용 USD 현금을 분리해 표시하도록 정리했다.

## 원문 요청사항
```text
“미장 주문 가능금액 계산 기준을 코드가 잘못 보고 있을 가능성”이 더 커.

한국투자증권 KIS API에서 해외주식은 국내주식이랑 주문/계좌 API 카테고리가 따로 있고, 해외주식 쪽에 해외주식 주문, 해외주식 매수가능금액조회, 해외증거금 통화별조회가 별도로 있음. 즉 국내주식 예수금/주문가능금액 조회값으로 미장 주문을 넣으면 충분한 돈이 있어 보여도 API에서는 “주문가능금액 초과”가 날 수 있어.

제일 가능성 높은 원인
1. 원화 예수금은 있는데 USD 주문가능금액이 없음

미국주식은 보통 달러 기준 주문가능금액으로 계산돼.
계좌에 원화가 있어도 해외주식 주문 API 입장에서는 해당 금액이 바로 주문가능금액으로 안 잡힐 수 있어.

확인해야 할 것:

해외주식 매수가능금액조회
해외증거금 통화별조회
해외주식 잔고

여기서 USD 기준 매수가능금액이 실제 주문금액보다 큰지 봐야 해.

2. 환전/통합증거금 설정 문제

한국투자증권 해외주식 쪽은 실시간 시세 신청 시에도 해당 통화 외화예수금 관련 안내가 있을 정도로, 해외거래는 통화 기준이 중요하게 분리돼 있음.

즉 계좌에 원화가 있어도 아래 중 하나가 안 되어 있으면 주문가능금액이 부족하다고 나올 수 있음.

1. 달러 환전이 안 되어 있음
2. 해외주식 거래 약정이 안 되어 있음
3. 통합증거금/자동환전 설정이 안 되어 있음
4. API 계좌가 해외주식 거래 가능한 계좌로 연결되지 않음

MTS에서 같은 종목을 직접 사봤을 때도 안 되면 계좌/환전/약정 문제고, MTS에서는 되는데 API만 안 되면 API 요청값 문제일 확률이 커.

3. 해외주식 주문 API가 아니라 국내주식 주문 API 로직을 재사용 중

국장은 잘 되는데 미장만 안 되는 경우, 코드에서 이런 실수가 많아.

국내주식 주문은 국내주식 주문 API를 쓰지만, 미장은 overseas_stock 쪽 API를 써야 함. 한국투자증권 공식 샘플 저장소도 국내주식은 domestic_stock, 해외주식은 overseas_stock으로 분리해둠.

특히 확인할 값:

URL: /uapi/overseas-stock/v1/trading/order
tr_id: 미국 매수는 TTTT1002U, 모의는 VTTT1002U 계열
OVRS_EXCG_CD: NASD / NYSE / AMEX 등
PDNO: AAPL, TSLA 같은 해외종목코드
ORD_QTY: 주문수량
OVRS_ORD_UNPR: 주문가격
ORD_SVR_DVSN_CD: 0

국내주식처럼 KRX, J, ORD_UNPR, PDNO=005930 이런 기준으로 보내면 미장 주문에서 금액 계산이 꼬일 수 있어.

4. 주문 가격을 원화 기준으로 넣고 있을 가능성

미국주식 주문가격은 달러 단가로 넣어야 해.

예를 들어 애플을 1주 사는데 현재가가 200달러면:

OVRS_ORD_UNPR = "200.00"
ORD_QTY = "1"

이런 식이어야 하는데, 원화 환산 가격인 280000 같은 값을 넣으면 API 입장에서는 280,000달러짜리 1주 주문으로 계산해서 바로 주문가능금액 초과가 뜰 수 있음.

이거 진짜 흔한 원인임.

5. 수수료/환율 여유분 없이 딱 맞게 주문함

미장은 단순히 현재가 × 수량만 보는 게 아니라 수수료, 환율, 증거금 계산 때문에 여유분이 필요할 수 있음.

예를 들어 USD 주문가능금액이 100달러인데 99.9달러 주문을 넣으면 거절될 수 있어.
처음 테스트는 아래처럼 아주 작게 해봐.

가능금액 100달러 기준
주문금액 70~80달러 이하로 테스트
바로 점검할 순서
1단계: 해외주식 매수가능금액조회 먼저 호출

국내 예수금 말고 해외주식 매수가능금액조회 API 결과를 봐야 함.

확인할 값은 대충 이런 쪽이야.

USD 매수가능금액
외화예수금
주문가능금액
해외증거금

여기서 0으로 나오면 코드 문제가 아니라 계좌/환전/약정 문제일 가능성이 큼.

2단계: MTS에서 같은 계좌로 미국주식 1주/소수점 말고 정규 주문 가능 여부 확인

MTS에서도 안 되면:

해외주식 거래 신청 안 됨
환전 안 됨
자동환전/통합증거금 미설정
계좌가 해외주식 불가 계좌

MTS에서는 되는데 API만 안 되면:

API TR_ID 오류
실전/모의 AppKey 혼용
해외주식 주문 URL 오류
시장코드 오류
주문가격 단위 오류
hashkey 누락
계좌번호/상품코드 오류
3단계: 실전/모의 키 섞였는지 확인

KIS는 실전투자계좌와 모의투자계좌 각각 APP Key, APP Secret이 따로 생성됨.

즉 이런 조합이면 오류 날 수 있어.

실전 URL + 모의 AppKey
모의 URL + 실전 AppKey
실전 계좌번호 + 모의 TR_ID
모의 계좌번호 + 실전 TR_ID

미국주식 실전 매수면 보통:

tr_id = TTTT1002U

미국주식 모의 매수면:

tr_id = VTTT1002U
결론

지금 에러는 미장 거래 락이라기보다는 거의 아래 중 하나야.

1. USD 주문가능금액이 실제로 부족함
2. 원화 예수금만 보고 주문 넣고 있음
3. 해외주식 매수가능금액조회가 아니라 국내 예수금 조회값을 쓰고 있음
4. 주문가격을 달러가 아니라 원화 환산가로 넣고 있음
5. 실전/모의 AppKey, URL, TR_ID가 섞임
6. 해외주식 거래 약정/환전/통합증거금 설정이 안 됨

가장 먼저 볼 건 이거야.

해외주식 매수가능금액조회 결과에서 USD 주문가능금액이 얼마로 나오는지

거기서 0이면 계좌 설정 문제고, 충분히 나오는데도 주문이 막히면 주문 payload 문제야.

원인 찾아서 해결해. 추가로 필요한 정보 있으면 나한테 요청해
```
