# 수익 집계 최적화 검증 (2026-10-07)

## 구현

- 계좌/사용자/실투자·모의투자별 영속 집계 저장. 서버 재시작 후에도 재사용.
- 과거 기간 집계와 오늘 집계를 분리. 과거는 6시간 재사용 후 정정 대조, 오늘은 30초 주기로 갱신 요청.
- 화면 요청은 저장된 집계만 읽고, 한투 조회/재계산은 계좌별 단일 백그라운드 작업으로 실행.
- 체결 대조 실패 시 기존 확정 집계 유지. 최초 미집계 금액은 0원으로 확정 표시하지 않음.
- 잔고/시세 조회 완료를 기다리던 프런트엔드 순서 제거.
- 날짜/Decimal DB 값 직렬화 및 VARCHAR(64) 저장 키 검증.

## 실측

로컬 실행 서버 3001, 실제 로그인된 대시보드에서 저장 집계 생성 후 확인.

| 항목 | 측정값 |
|---|---:|
| 주간 서버 조회 | 79.30 ms |
| 월간 서버 조회 | 79.71 ms |
| 월간 기간 선택 → 수익 카드 표시 | 176 ms (해당 요청 서버 68.75 ms) |
| 당일 기간 선택 → 수익 카드 표시 | 172 ms (해당 요청 서버 66.76 ms) |

브라우저 수치는 기간 선택 실행 직전부터 수익 카드 visible 확인까지의 벽시계 시간이다. 전체 페이지 최초 로딩 시간이나 한투 최신 체결 대조 시간과는 다르다. 최초 집계가 없는 계좌/기간은 백그라운드 초기 생성 시간이 필요하다. 표시 시각과 갱신 중 안내로 저장값임을 구분한다.
