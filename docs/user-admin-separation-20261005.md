# 일반 사용자 / 관리자 기능 분리

일반 사용자는 개인 KIS API와 FireGate 연결로 무한매수를 운용한다.
기존 로그인 계정의 서버 측 관리자 판정을 사용하며 별도 계정이나 자격증명을 만들지 않았다.
연결/동기화는 자동매매 ON 동의와 별개다. 종목 잠금 및 주문 위험 확인은 유지한다.

## 변경

- 국내/미국 단타 API: LIVE/PAPER 모두 관리자 전용. 기존 사용자 허용 목록은 권한을 부여하지 않는다.
- 공통 제어 API: 일반 사용자의 단타 설정 변경을 저장 전에 차단.
- 주문 정책: 매수·매도·정정·취소의 단타 주문 경로에서 관리자 권한 재확인.
- LIVE 워커: 일반 사용자 단타 작업은 생성하지 않고, 이미 실행 중인 작업도 매 주기 권한 확인.
- PAPER 기능 판정: 사용자 역할을 확인하고 일반 사용자는 단타 기능 비활성.
- 일반 사용자 메뉴: 대시보드/무한매수/거래이력. 단타 스위치/설정/연구 메뉴 숨김.
- 거래이력 기본 탭: 사이클. 단타 이력 탭은 관리자 표시. 과거 기록은 삭제하지 않음.
- 설정: KIS 연결 → FireGate 연결/사이클 동기화 이동 안내 추가.
- 자산과 기존 보유 조회, 종목 잠금은 유지. 관리자 미리보기는 UI 편의 기능이며 보안 경계가 아님.

## 검증

전체 오프라인 테스트 340개 통과. 일반 사용자 무한매수 허용, 단타 ON/주문 차단,
관리자 권한 상실 후 기존 ON 차단, PAPER의 역할 제한, 일반 사용자 워커가 LOC만 실행,
국내/미국 접근 API의 이전 허용 목록 무시, 공통 설정의 단타 필드 무시를 포함한다.
기존 계좌 격리·체결 이력·잠금 테스트도 함께 실행했다.

운영 DB의 사용자 역할, API 키, 계좌, 보유, 거래이력 및 ON/OFF는 직접 수정하지 않았다.
신규 사용자의 실제 KIS/Google 인증은 이 검증에서 대신 수행하지 않았다.
단타 전략 수익성 검증이나 KIS 실체결 검증 완료를 의미하지 않는다.
