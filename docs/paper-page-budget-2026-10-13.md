# 모의 국장 페이지 시드·초기 로딩 수정

## 재현

서버의 주문가능 조회는 정상이나 페이지 첫 조회와 자동 갱신은 `use_cache_only=True`를 사용했다. 캐시 누락 시 `budget_status=unavailable`인 0원 응답을 받은 뒤 실조회로 갱신하지 않아 총자산·시드·계획이 0원으로 남았다. 수동 시드 적용을 누르면 실조회가 이뤄져 정상 잔고가 표시됐다.

모의 동적 배분이 요청 시드 500만 원을 무시하고 잔고의 70%인 약 6,851만 원을 총 시드로 표시하는 문제도 재현됐다.

## 수정

- PAPER 페이지 최초/자동 상태 조회에서 예산 캐시가 없을 때만 8초 요청 예산으로 브로커 조회를 수행한다. 정상 캐시는 기존 TTL로 재사용한다.
- PAPER 동적 배분은 양수 요청 시드를 상한으로 적용한다. LIVE 배분 로직은 그대로 둔다.
- 446개 회귀 테스트 통과. 캐시 누락 갱신, 정상 캐시 및 LIVE 추가조회 없음, 모의 요청 상한과 LIVE 기존 계산 유지 테스트 포함.
- 화면에 입력돼 있던 500만 원을 시드 적용 버튼으로 저장하며 재현했다. LIVE 설정/주문은 변경하지 않았다.

실제 거래 체결 확인과 백테스트 수익성 검증은 이 수정의 완료 범위와 별개다.

## 2026-10-14 UI 실행 확인

- 단일 종목 백테스트 후 전 종목 재훈련 및 브로커 재조회까지 기다리던 호출을 제거했다. 완료 메시지에 수익률, 손익, 최대낙폭, 검증 구간 수익률을 표시한다.
- 배포 버전 감시가 현재 main.js 버전과 응답 HTML의 첫 번째 vendor.js 버전을 비교하여 재로딩을 반복했다. 양쪽 모두 main.js를 선택하도록 수정했다.
- PAPER 3002 새 화면에서 총자산 97,874,059원, 총/남은 시드 5,000,000원, 233740 시세 7,000원 표시 확인.
- 현재 종목 백테스트 버튼 직접 실행: 233740 / V-REV / 5일 / 1분봉 / 시드 500만 원. 수수료 반영 수익률 -4.766%, 손익 -238,299원, 최대낙폭 4.766%, 검증 구간 -3.237%. 완료 메시지와 버튼 재활성화 확인. 수익성 통과를 의미하지 않는다.
- 해외 보유 조회 실패 안내는 여전히 관측됐다. 이 항목이나 실제 브로커 체결까지 완료됐다고 판단하지 않는다.
- LIVE ON/OFF, 주문, 취소는 변경하지 않았다.
