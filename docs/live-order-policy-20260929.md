# 실투자 전략별 주문 권한 (2026-09-29)

이 문서는 account-isolation-20260927.md의 영구 실투자 차단/환경변수 허용 설명을 대체한다.

- 실투자 3001과 모의투자 3002는 별도 거래 DB를 사용한다.
- Windows 시작 작업은 start-stock8.ps1로 두 서버를 시작한다. 서버 시작은 주문 동의가 아니다.
- LIVE 무한매수와 단타는 각각 기본 OFF. 사용자가 위험 경고를 확인해야 ON으로 저장된다.
- LIVE 종목은 기본 잠금. 명시적으로 잠금 해제된 종목만 주문할 수 있다.
- 잠금은 자동 매수·매도·손절·익절·정정·취소를 차단한다. 이미 증권사에 접수된 주문은 취소하지 않는다.
- 권한은 증권사와 계좌번호 기준이다. 기존 global live_orders_enabled만으로 주문할 수 없다.
- KIS/Toss는 대기 후 전송 직전에도 권한을 DB에서 다시 검사한다. 전략 출처가 없거나 조회 실패 시 차단한다.
- LIVE 워커는 명시적으로 허용된 계좌 정책만 처리하며 진입, 청산 감시, LOC 작업을 분리한다.
- 검증 중 실투자 ON, 종목 잠금 해제, 실제 주문을 수행하지 않았다. 실제 체결 검증 완료를 의미하지 않는다.

주문 권한 16건, 브로커 안전성 17건과 기존 관련 회귀 테스트 통과. 브라우저에서 API 설정 폼과 분리된 OFF 제어 화면 확인.
