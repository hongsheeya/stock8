# 실주문 없는 추가 검증 — 2026-10-02

## 범위

현재 LIVE 계좌의 무한매수·국장·미장 설정 OFF 확인. 사용자 설정이나 종목 잠금 변경 없음.
실제 브로커에는 국내 잔고, 해외 잔고, 현재잔고 GET만 호출. 주문, 정정, 취소 및 토큰 발급은 진단 코드에서 금지.

## 통과

- 생산 코드의 account_job 본문을 가짜 엔진으로 실행: OFF에서 매수·매도·LOC 호출 없음.
- 국장·미장 진입/청산 각각 해당 시장만 호출. 반대 시장 ON으로 OFF 시장이 실행되지 않음.
- 주문 경계의 전략별 권한, 종목 잠금, 변경 계좌, 동의 확인 테스트 통과.
- 토큰 거절 후 GET 1회 복구, POST 재전송 금지, 동시 갱신 토큰 보존 테스트 통과.
- 계정 분리, 체결 이력 처리, 자산 계산 회귀 테스트 통과.
- 이번 실행: 143개 테스트 통과(11개 테스트 파일, 재실행 중복 제외).

## 추가 수정

profit_summary가 WIZ ResponseException(정상 HTTP 응답 종료)을 일반 오류로 잡아
`season.core.exception.response`를 표시하던 경로 수정. 해당 예외를 재현하는 회귀 테스트 추가.
계좌 연결 재검사를 통과하지 못해도 인증된 사용자의 저장된 수익 이력 조회는 가능하도록 연결 검사와 분리.

## 아직 통과로 판정하지 않은 항목

- 대시보드 통합 순자산의 한투 화면과의 완전 일치(외화 환율·미결제·합계 범위 대조 필요).

- 실제 주문 접수→체결→실현손익 전체 흐름: 실주문하지 않았으므로 검증하지 않음.
