- 실제 세션 분봉 최소 20개 미만은 신규 매수 차단. 미확인/시세-only fallback도 차단.
- 국내 분봉 요청 5일, 이전 세션 종가를 라이브/연구 앵커로 통일. 첫 세션은 종가를 시가로 대체하지 않고 진입에서 제외.
- 시세 캐시 갱신과 분봉 데이터 생성 시각 분리: 자주 조회해도 분봉 캐시가 무한 연장되지 않음.
- 매수만 차단하며 보유 포지션의 청산은 유지.
- 전체 unittest 434건 통과. 신규 5건은 워밍업 경계, 첫 세션, 전일 종가, 라이브 신호, 캐시 갱신을 검증.

## 아직 완료되지 않은 범위

테스트는 브로커 대역을 이용한 오프라인 검증이며 KIS PAPER 체결 실증이 아니다.
기존 실행 저장소에는 미커밋 변경과 공유 LIVE/PAPER 소스가 있어 별도 worktree에서 작업했다.
실행 서버 배포·재시작, LIVE 주문·설정 변경, data/ 커밋은 하지 않았다.

PAPER에서 브로커 증거를 모아야 하는 항목:

1. 예약 매도 취소 요청 → 취소 확인 → 손절 접수/체결.
2. 15:10~15:20 익절/정리/이월 및 volume_breakout 청산.
3. 체결 후 재진입 쿨다운.
4. 즉시 점검 예약 모드 무주문 및 같은 거래일 여러 체결의 1회차 반영.

나머지 후속(백테스트 지표/홀드아웃/시뮬레이터, 미국 단타, 무한매수 장부·예약)은 별도 변경과 검증이 필요하다.
이 안전 수정은 수익성 개선의 실증이 아니며 단타 LIVE 활성화 근거로 사용하지 않는다.
