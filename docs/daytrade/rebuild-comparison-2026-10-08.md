# 단타 평가 계층 재구성과 Vibe 후보 비교

## 상태

평가 엔진 수정 및 오프라인 후보 비교를 수행했습니다. **실전 단타 전체 재작성·배포 완료가 아닙니다.** 실주문·스위치·무한매수·계좌 DB는 변경하지 않았습니다. 통과한 외부 후보가 없어 운영 전략 목록에도 추가하지 않았습니다.

## 수정한 코드

- 공통 오프라인 목표 비중 재생기 `research_replay.py`: 다음 동일 세션 봉 시가 체결, 정수 수량, 현금 한도, 양방향 비용, 일말 청산, 분봉 평가자산, 매도 손익과 현금 일치 검사.
- 기존 집계: 장중 평가 곡선을 포함한 낙폭, 수익 거래만으로 평균 이익 계산, 정의되지 않은 Profit Factor를 금액으로 반환하던 오류 수정. 구 API의 PF는 0과 `profit_factor_defined=false`로 표현하며 새 재생기는 null을 사용.
- 거래 승률과 일별 승률, 주문 이벤트 수를 분리 표기.
- 보유 시간은 봉 개수가 아니라 체결 타임스탬프 기반 수량 가중 평균 분으로 계산.
- 기존 거래량 돌파 시뮬레이션을 당일 봉 종가 체결에서 확정 봉 판단/다음 봉 시가 체결로 변경.
- 최적화에 10개 이상 세션이 있으면 마지막 20%를 파라미터 선택에서 제외하고 선택된 모델을 한 번 평가. 짧은 표본·반복 관찰의 한계는 유지.

## 재현

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/compare-vibe-strategies.py --zip C:/dev/vibe-trading-strategies.zip
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -q
```

입력은 로컬 `data/reconciliation-audits/martin-bars-20261004-*.json` 5개 파일입니다. 입력·첨부 소스 SHA256은 출력 JSON에 기록합니다. 외부 예제는 검토한 technical-basic/multi-factor 두 파일만 해시 일치 후 읽고, 데모 실행·네트워크 도우미는 실행하지 않습니다. ZIP과 가격 데이터는 저장소에 새로 포함하지 않습니다.

## 실험 조건과 한계

- 삼성전자, SK하이닉스, HLB제약(047920), 한국콜마(161890), KODEX200(069500) 고정 5종목.
- 공통 시각 5분봉, 종목별 독립 시드 100만원. 종목 간 현금 이전 없음.
- 2026-07-08~08-19 개발 29개 날짜, 08-20~09-09 검증 15개 날짜, 09-10~10-02 마지막 평가 15개 날짜.
- 기존에 관찰한 데이터이므로 이 마지막 평가도 새로운 독립 OOS 성과가 아님. 거래 가능 날짜·분봉 누락·선정 편향 및 최신 시장 대표성에 한계가 있음.
- 연구 비용: 매수 4bp, 주식 매도 22bp, ETF 매도 4bp. 실제 수수료·세율의 주장 아님. 두 배 비용 스트레스도 실행.
- 외부 음수 비중은 현금으로 처리하고 매일 청산. 원본 일봉 롱/숏 전략과 다른 **국내 분봉 롱온리 적용 실험**임.
- 멀티팩터의 20봉 리밸런싱은 여기서 20일이 아니라 20개의 5분봉. 원본 장기 전략의 우열을 입증하지 않음.
- VREV/돌파는 핵심 신호의 공통 엔진 적용본이며 실제 계좌 엔진의 모든 청산·익일 보유 로직을 재현한 것이 아님. 진입 기준가는 신호 종가이므로 실제 체결 원가 기반 손절과 차이가 있음.
- 낙폭은 종가 평가와 저가 평가를 별도 계산. 같은 봉 안의 고가·저가 발생 순서, 호가 잔량·부분체결은 재현하지 않음.

V-REV도 검증 구간 비용 2배에서 **-0.810%**입니다. 마지막 구간만 보고 최선으로 선정하지 않습니다.

외부 두 후보는 각 60개 시점/종목 절단 비교에서 신호 불일치 0개였습니다. 유한한 검사이며 미래 정보가 절대 없다는 증명은 아닙니다.

사전 연구 선별 기준은 두 평가 구간 각각 순수익 양수, 매도 이벤트 30개 이상, PF 1.1 이상, 저가 평가 낙폭 10% 이하, 두 배 비용에서도 양수였습니다. **두 외부 후보 모두 탈락**했습니다. 이 기준 통과조차 실거래 승인과는 별개입니다.

## 외부 나머지 예제

엘리엇·하모닉·cross-market 등 미래 데이터 의존성이 발견된 원본은 수익 경쟁에 넣지 않았습니다. SMC의 의존 라이브러리·신호 확정 시점, 이벤트·재무 데이터 필요 전략, 비전략 템플릿도 별도 처리 대상입니다. 18개 모두 재실행했다고 주장하지 않습니다. 원본 일봉 전체 기간 재현에는 첨부 ZIP에 없는 원천 데이터·외부 백테스트 엔진이 추가로 필요합니다.

## 남은 재구성

1. 실전과 연구가 동일한 상태 전이를 쓰도록 진입·청산을 완전히 통합. 현재 수정본을 바로 운영 배포하지 않음.
2. 고정 금액 수익/최소 거래빈도 필터를 위험·거래당 기대손익·표본 불확실성 중심으로 대체하고 비교 검증.
3. 더 긴 다국면·다종목 표본과 전향적 PAPER 검증 확보.
4. 수동 재학습 작업 큐/진행 조회, 새 최종 평가 결과의 UI 연동.

기존 생성 문서의 수익률은 새 엔진의 성능으로 재사용하면 안 됩니다. 이번 변경으로 “최적 전략 발견” 또는 “전체 실전 검증 완료”를 선언하지 않습니다.
