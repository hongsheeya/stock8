# 외부 뉴스·이벤트 기반 단타 예측모델 검토

- **작성일**: 2026-04-13
- **대상**: `/daytrade` 국내 단타 연구실
- **목적**: 외부 뉴스/공시/이벤트 데이터를 현재 전략 엔진에 결합할 수 있는지 사전 타당성 검토

## 결론

**가능은 하다.** 다만 바로 “뉴스만 넣으면 예측력이 크게 오른다” 수준은 아니고,
현재 구조에서는 **1차로 이벤트 필터(event filter)**, **2차로 점수 보정(score adjustment)**, **3차로 별도 예측모델** 순서로 가는 것이 현실적이다.

즉시 권장하는 방향은 다음과 같다.

1. **공시/이벤트 기반 차단 필터**부터 붙인다.
2. 이후 **뉴스 감성/키워드 점수**를 보조 피처로 추가한다.
3. 충분한 라벨 데이터가 쌓이면 그때 **예측모델**로 확장한다.

## 왜 바로 예측모델이 아닌가

현재 `/daytrade`는 아래 데이터가 이미 강하다.

- 분봉 가격
- 거래량
- VWAP/이동평균/RSI/MACD
- 실시간 시그널
- 전략별 백테스트 결과

반면 뉴스/이벤트 데이터는 아래 문제가 있다.

- 기사 시각과 실제 시장 반영 시각이 다를 수 있음
- 같은 뉴스라도 종목별 영향이 비대칭적임
- 라이선스 이슈가 큼
- 국내 장중 초단기 단타에서는 **지연 1~5분**도 효과를 크게 깎을 수 있음

그래서 초기에 가장 효과적인 것은 “예측”보다 **위험 필터링**이다.

## 활용 가능한 데이터 소스

### 1. Open DART 공시
- 장점
  - 공식 소스
  - API 사용 가능
  - 유상증자/전환사채/주요사항보고 등 강한 이벤트 반영 가능
- 단점
  - 기사형 뉴스보다 범위가 좁음
  - 기업코드 매핑 관리 필요
  - 초단타용으로는 장중 즉시성 한계가 있을 수 있음
- 권장 용도
  - **악재/대형 이벤트 발생 종목 신규 진입 차단**
  - 이벤트 발생 종목 위험도 가중치 부여

### 2. 증권/포털 뉴스 API
- 장점
  - 기사 커버리지 넓음
  - 테마/정책/실적 기대감 등 반영 가능
- 단점
  - 라이선스·비용·재배포 제약 가능성 큼
  - 중복 기사·어뷰징 기사 제거 필요
  - 종목 매핑 정확도 이슈
- 권장 용도
  - **감성 점수(sentiment)**
  - 급등 사유 키워드 태깅
  - 테마 이벤트 점수

### 3. 거래소/공시 이벤트성 데이터
- 예시
  - 거래정지
  - 투자경고/위험/주의
  - 관리종목/불성실공시
- 장점
  - 리스크 필터로 매우 유효
- 단점
  - 소스 표준화 필요
- 권장 용도
  - **무조건 차단 필터**

## `/daytrade`에 붙이는 현실적인 결합 방식

### 단계 1. 이벤트 필터
현재 `daytrade.py`의 `event_filter` 자리에 결합.

목표:
- 특정 종목에 공시/위험 이벤트가 있으면 신규 BUY 차단
- 이미 보유 중이면 경고 레벨 상향

예시 규칙:
- 최근 $30$분 내 악재 공시 → `blocked=true`
- 투자위험/거래정지/관리종목 이벤트 → 신규 BUY 금지
- 호재 공시는 차단이 아니라 `warning/info`로만 표기

### 단계 2. 랭킹 점수 보정
추천 점수에 뉴스/이벤트 점수를 작은 비중으로 합산.

예시:
$$
score_{final} = score_{backtest} + w_1 \cdot sentiment + w_2 \cdot event\_quality - w_3 \cdot risk\_penalty
$$

권장:
- 초기에는 $w_1, w_2$를 작게 두고
- 필터 중심으로 운영한 뒤,
- 실제 체감 성능이 확인되면 확대

### 단계 3. 예측모델
충분한 학습 데이터가 모이면,
“뉴스/이벤트 발표 후 $5$분, $15$분, $30$분 수익률” 같은 라벨로 별도 모델 가능.

가능 모델 예:
- LightGBM / XGBoost
- 로지스틱 회귀(베이스라인)
- 텍스트 임베딩 + 탭ुल러 피처 결합 모델

다만 현재 프로젝트에는 우선 아래가 필요하다.
- 종목별 뉴스 수집 저장소
- 이벤트 시각 정규화
- 기사-종목 매핑
- 장중 라벨 데이터셋 축적

- Open DART 공시 연동
- 이벤트 필터 스냅샷 UI 표시
- 신규 BUY 차단 규칙

### 중간
- 뉴스 기사 수집/정규화
- 종목 키워드 매핑
- 감성/키워드 점수화

### 높음
- 뉴스+분봉 결합 예측모델
- 실시간 지연 최소화
- 라이선스 안정성 확보
- 모델 재학습/성능 검증 자동화

## 추천 PoC 범위

### PoC 1 — 공시 기반 위험 필터
가장 추천.

범위:
- Open DART 연동
- 종목별 최근 공시 조회
- 공시 유형별 severity 분류
- `/daytrade` 피처/리스크 패널에 노출
- 악재 이벤트 시 신규 BUY 차단

효과:
- 구현 부담 대비 실전 리스크 저감 효과가 큼

### PoC 2 — 뉴스 감성 보조점수
PoC 1 성공 후 추천.

범위:
- 허용 가능한 뉴스 소스 1개 선정
- 기사 중복 제거
- 종목별 최근 기사 20~50건 집계
- 간단한 긍정/부정/리스크 키워드 스코어
- 추천 점수에 작은 가중치로 반영

### PoC 3 — 예측모델
PoC 1, 2 이후.

범위:
- 기사 시각과 분봉 시각 정렬
- 발표 후 단기 수익률 라벨링
- 분봉 피처 + 이벤트 피처 결합 모델
- 전략별로 별도 평가

## 프로젝트 적용 권고

현재는 다음 순서가 가장 적절하다.

1. `event_filter`를 **실제 Open DART 기반**으로 교체
2. `/daytrade`에서 이벤트 severity / reason / blocked 상태 표시
3. BUY 차단 규칙부터 운영
4. 이후 뉴스 소스 계약/라이선스 정리
5. 그 다음 감성 점수와 예측모델 검토

## 사용자 보고용 요약

- 외부 뉴스/이벤트 기반 모델은 **가능하다**.
- 다만 바로 풀모델보다, **공시/이벤트 필터 → 뉴스 보조점수 → 예측모델** 순이 더 안전하다.
- 현재 구조에는 **Open DART 기반 이벤트 필터 PoC**가 가장 먼저 들어갈 만하다.
- 뉴스 기반은 데이터 비용/라이선스/지연시간 검토가 더 필요하다.
