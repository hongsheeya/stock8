# 국장 후보 탐색 수정

## 확인한 결함

- candidate_universe가 순위 조회 부재/만료에도 고정 53종목의 순환 목록과 방향성 ETF를 혼합했다.
- recommend가 유효한 추천 캐시를 반환하기 전에 순위를 확인하지 않아 새로운 후보 반영이 추천 유효시간에 묶였다.
- 가격·거래량·거래대금이 0이면 조건문이 필터 검사를 생략했다.

## 변경

- 운영 후보는 300초 이내 성공한 동적 조회 결과만 사용한다. 고정 목록은 명시적인 research_candidate_universe로 분리했다.
- 조회 실패(unavailable)와 조건에 맞는 후보 없음(empty)을 구분한다. 실패 시 예전 후보를 비우며 반복 실패도 300초 동안 재요청하지 않는다.
- recommend 호출 때 탐색 TTL을 확인한다. 후보 종목 집합이 저장된 discovery_symbols와 다르면 추천 캐시가 유효해도 재검증한다. 신규 후보는 검증 우회 없이 auto_train을 통과해야 한다.
- 새 후보 검증 예외 시 국장은 고정 목록으로 대체하지 않고 신규 진입을 보류한다.
- 누락된 가격·거래량·거래대금은 통과시키지 않는다.

이는 독립 탐색 스케줄러를 신설한 변경은 아니다. recommend 호출 빈도보다 빠르게 탐색하지 않으며 재학습 지연도 남는다. ETF는 고정 삽입하지 않지만 실제 순위에서 기존 필터를 통과하면 후보가 될 수 있다. 보유 종목 청산 경로는 수정하지 않았다.

## 검증 및 배포 범위

전체 단위 테스트 424개 통과. 신규 6개 테스트는 고정 목록 자동 복귀 금지, 만료 후보 제외, 실패 후 재시도 제한, 빈 조회 구분, 누락 거래량 제외, 후보 변경 시 유효 추천 무효화를 검사한다. 기존 연구 목록 테스트는 명시적 연구 메서드로 변경했다.

실행 서버 배포/재시작 및 실제 KIS 장중 검증은 수행하지 않았다. 주문·ON/OFF·잠금·무한매수 데이터 변경 없음. 현재 화면에 즉시 적용되었다고 해석하면 안 된다.
