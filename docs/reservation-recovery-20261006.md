# 접수 불명 요청 복구

사용자가 KIS 앱에도 SOXL 159.27달러 2주 주문이 없음을 직접 확인했다.
대상은 2026-10-06T02:15:18.438280, TTTT3014U 요청 하나다.

- 복구 스크립트는 대상 값 전체 일치 여부를 검사하고 DB 백업을 만든 뒤 사용자별 보류 키와 값이 같은 구형 미러만 해제한다.
- 주문 전송/취소, ON/OFF, 종목 잠금은 변경하지 않는다. 기존 사용자 ON 정책에 따른 워커 동작은 재개될 수 있다.
- 이후 접수 불명은 5분 간격으로 예약 및 주문/체결을 자동 대조한다. 조회 실패/미완료 페이지는 빈 결과로 취급하지 않는다.
- 동일 조건 후보와 조회 시각을 반환하되, 단순 조회 부재만으로 자동 재전송하지 않는다. 자동 대조와 자동 차단 해제는 구분한다.
- 테스트 371개 통과. 실제 접수 성공 여부는 별도 KIS 조회로 확인한다.
